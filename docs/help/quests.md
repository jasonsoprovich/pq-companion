# Quests

Self-contained quest walkthroughs built into the app, so you don't have to tab out to a wiki to remember a turn-in order or which mob drops a piece.

### Quests in the database explorer

A dedicated Quests section lists quest walkthroughs you can read step by step, with the items involved linked back to their database entries.

### Quests tab on items

Open any item and its Quests tab shows every quest the item is part of — both the quests that *reward* it and the ones it gets *turned in* to — each linked back to the full walkthrough and the other items in the chain.

### Quest-chain to-do lists

Multi-step keys and long reward chains are laid out as a to-do list so you can see the whole path at a glance and track what's left.
