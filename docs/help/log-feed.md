# Log Feed & Log Replay

The **Log Feed** shows what PQ Companion reads from your log, as it reads
it. Use it to confirm the app is seeing your game, or to find the exact
wording of a line for a trigger.

- **Live** shows parsed events as they arrive: hits, misses, casts, spell
  landings, resists, fades, heals, deaths and zoning.
- **Browse** pages through your whole log file without EverQuest running,
  with a type filter and text search.

### Log Replay

Replay an old log file through the app as if it were happening now — handy
for testing triggers, timers and overlays outside the game. Pick a file,
set start and end points, and use play, pause and stop. Custom overlays
update live during a replay and return to their earlier state when it
stops.
