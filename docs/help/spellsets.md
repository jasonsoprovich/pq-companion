# Spellsets

**Prerequisite:** Zeal-exported `_spellsets.ini`.

Reads Zeal's `_spellsets.ini` and surfaces every saved spellset as a card with the eight gems laid out vertically for quick scanning. Rename sets inline, add and remove sets from inside the app, or import another character's spellsets from their `.ini`.

Imports are filtered: spells that are off-class for the active character or above the character's level are flagged and blocked at import, so you never end up with a set you can't actually load in-game.
