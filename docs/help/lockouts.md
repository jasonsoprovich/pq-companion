# Lockouts

**Prerequisite:** `/log on`, then run `/sll` in-game.

The Lockouts page turns your `/sll` output into live countdowns, so you always know when an instance or flagged encounter is available to you again instead of walking up to a locked zone. Both loot lockouts and legacy lockouts are parsed and shown with the time remaining.

### Per character

Lockouts are stored per character, so each alt keeps its own set of timers. Switch characters with the global switcher and the list follows. Run `/sll` whenever you want to refresh — the countdowns update the moment the new output lands in the log.

### Absolute unlock time

Each active lockout shows the exact date and time it frees up in your local timezone right next to the live countdown (e.g. `07/04 3:25 PM`), so you can see exactly when something's available without doing the math yourself. Hover the countdown for the full date and time.

### Zone Loot Lockouts

A per-zone **Loot Lockouts** sub-tab shows every one of your characters' lockout status for that zone side by side, so you can see at a glance which alts are clear to go back in instead of checking each character one at a time. Log backfill can also seed lockout history from your existing logs, the same as other trackers.

### Plane of Time

Run `#timelockout` (or `#timelockout 1` through `6` for one phase's detail) and a Plane of Time section appears alongside your loot and legacy lockouts, showing which encounters are available now and when a defeated one resets.
